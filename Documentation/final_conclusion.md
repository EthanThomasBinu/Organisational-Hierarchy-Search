# Final Conclusion

The organisational hierarchy is best represented using a child-sibling tree because the structure naturally models the CEO, departments, and sub-departments.

Level-order traversal successfully displays all 8 nodes in hierarchical breadth-first order.

For department searching, Binary Search is the better choice when the department list is sorted. In the recorded tests, Binary Search used 9 total comparisons compared with 17 for Linear Search.

Therefore, the most suitable solution is a **child-sibling tree for organisational reporting** combined with a **sorted array and Binary Search for efficient department searching**.
